# Python style guide

Python code follows the
[Google Python Style Guide](https://google.github.io/styleguide/pyguide.html), except where ruff
or [CONTRIBUTING.md](../../CONTRIBUTING.md) already decides. A comment that applies it cites it
as `[python/google]` with a link to the section.

The [general points](README.md#points) apply too, and ruff
([CONTRIBUTING.md](../../CONTRIBUTING.md#quality-gates)) covers the rest. Python-specific points
are added here as review finds them.
