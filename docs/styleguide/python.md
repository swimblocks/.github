# Python style guide

Python code follows the
[Google Python Style Guide](https://google.github.io/styleguide/pyguide.html), except where ruff
or [CONTRIBUTING.md](../../CONTRIBUTING.md) already decides. Its ID here is `python/google`.

Ruff ([CONTRIBUTING.md](../../CONTRIBUTING.md#quality-gates)) enforces the parts a machine can
check. Beyond the [general points](README.md), Python points that take judgement are added here
as review finds them.
